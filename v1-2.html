Settings

GreenLight works offline using the Bible rule engine. Add a free YouTube API key to unlock live data: autocomplete demand, outlier scans, and trend windows.
How to get a free key (5 minutes, no card needed)
  1. Go to console.cloud.google.com and sign in with any Google account.
  2. Create a project (top bar → New Project → name it anything).
  3. Search "YouTube Data API v3" in the top search bar → open it → press Enable.
  4. Left menu → Credentials → Create Credentials → API key. Copy it.
  5. Paste it above and hit Save. Leave the key unrestricted (it's for personal use).
Free quota is 10,000 units/day — each verdict costs ~202 units, so roughly 49 full verdicts per day. Quota resets daily.
Move this app + history to another device
  1. Put this HTML file in Google Drive / iCloud / OneDrive and open it in any browser on any device. On iPad/Android use Share → Add to Home Screen for an app feel.
  2. History and your key are saved per-device (in the browser). Use Export below to move history between devices.
Your history, watchlist, AND YouTube API key get saved to a private note in YOUR GitHub account. Paste the same token on each device and everything stays in sync — set the API key up once, it follows you. Pulls when you open the app, pushes after changes.
How to set up sync (3 minutes, free)
  1. Make a free account at github.com if you don't have one.
  2. Go to github.com/settings/personal-access-tokens/new.
  3. Name it "greenlight", set expiration to 1 year.
  4. Under Account permissions find Gists → set to Read and write. Nothing else needed.
  5. Generate, copy the token, paste it above on EVERY device you use, hit Save then Sync now.
The token only grants access to gists (private notes) — not your code or account. Your YouTube API key syncs through the private gist; the GitHub token itself never syncs — it's the one thing you paste per device.
